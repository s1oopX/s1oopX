### Core Focus & Engineering Foundations

- **后端架构与高并发**：深耕 Java 21 / Spring Boot 体系，关注高并发抢号链路、分布式锁、缓存一致性与数据对账。
- **边缘网络与系统交付**：深度实践 Cloudflare (Edge/WAF/Tunnel)、公网分流，以及受限资源（1核/1G）下的 VPS 极限加固与容器运维。
- **前端性能与工具开发**：关注 Web Vitals 首屏性能优化（Lighthouse 100分实践）；使用 Rust + Tauri 打造低资源占用的本地原生工具。
- **AI 代理与工作流探索**：关注 Agent 上下文连续性、模型 API 路由调度与文本信号分析。

### Selected Projects

#### Backend & High-Concurrency
- **[ReserveX](https://github.com/s1oopX/ReserveX)** — 模块化单体预约系统
  - 技术栈：Java 21 / Spring Boot 3.5 / Redis / Sharding 分库分表 / React 18
  - 核心攻坚：Redis 预占防超卖 + 消息补偿对账链路，保障高并发下的最终一致性与容灾。
- **[DjangoBlog](https://github.com/s1oopX/DjangoBlog)** — 全栈 Web 博客系统
  - 技术栈：Python / Django / SQLite / HTML
  - 亮点：基于经典 MVC 架构的完整全栈 Web 应用实践，涵盖内容管理与用户权限体系。

#### Local Native & Productivity
- **[clipmaster-tauri](https://github.com/s1oopX/clipmaster-tauri)** — 极简跨平台剪贴板管理工具
  - 技术栈：Rust + Tauri + TypeScript
  - 亮点：低内存占用，本地隐私优先，探索现代 Rust 在桌面端的系统级交互与状态管理。
- **[codex-api-switchboard](https://github.com/s1oopX/codex-api-switchboard)** — 隐私优先的 API 配置转换工具
  - 技术栈：HTML / JavaScript
  - 亮点：纯前端本地处理，快速完成自定义 API 格式转换与配置管理，零数据上传。

#### Edge Delivery & Web Performance
- **[narrow-x](https://github.com/s1oopX/narrow-x)** — 内容优先 Astro 博客主题
  - 亮点：首屏加载性能优化（FCP < 0.5s / 零运行时开销），结合 Cloudflare 边缘缓存与中文字体子集化。
- **[s1oop-cloudflare-blog-public](https://github.com/s1oopX/s1oop-cloudflare-blog-public)** — 边缘托管轻量内容站
  - 技术栈：JavaScript / Cloudflare Pages / Workers
  - 亮点：探索基于边缘运行时的极低延迟页面分发与自动化部署流程。

#### AI Systems, Signal Processing & DevOps
- **[grok2api-enhanced](https://github.com/s1oopX/grok2api-enhanced)** — 增强型 API 代理与出口路由调度
  - 技术栈：Python / Docker / Mihomo
  - 亮点：集成可视化出口分流与看板，实现高可用模型接入与跨区域网络优化。
- **[SentimentPlatform-Open](https://github.com/s1oopX/SentimentPlatform-Open)** — 文本与情绪信号分析平台
  - 技术栈：Python
  - 亮点：针对文本反馈与产品信号进行多维度清洗、情绪分类与趋势挖掘。
- **[agent-memory-workflow](https://github.com/s1oopX/agent-memory-workflow)** — Agent 记忆与上下文工作流研究
  - 技术栈：PowerShell / Markdown
  - 亮点：探索 AI Agent 在长任务中的上下文连续性、状态持久化与记忆检索工作流。
- **[teamspeak3-vps-oneclick](https://github.com/s1oopX/teamspeak3-vps-oneclick)** — VPS 容器化一键部署方案
  - 技术栈：Shell / Docker Compose
  - 亮点：专为 Linux VPS 设计的零配置快速部署脚本，包含持久化存储与安全网络隔离。
